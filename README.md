-# 端口扫描器

一个基于 Python 的多线程端口扫描工具，支持结果导出 CSV。

## 功能

- 多线程扫描，速度快
- 支持自定义端口范围
- 结果导出为 CSV 文件
- 命令行传参，方便使用

## 用法

python scan.py <ip> [-p 端口范围] [-o 输出文件]

## 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| ip | 目标 IP（必填） | 无 |
| -p / --ports | 端口范围，如 1-1000 | 1-100 |
| -o / --output | 输出 CSV 文件 | result.csv |

## 示例

python scan.py 127.0.0.1
python scan.py 127.0.0.1 -p 1-1000
python scan.py 127.0.0.1 -p 1-1000 -o out.csv
python scan.py --help

## 输出示例

端口,状态
80,开放
443,开放

## 注意事项

- 仅用于扫描自己拥有或已获授权的设备
- 未经授权扫描他人设备可能违法
